# WindowsAPICodePackCore

Task Dialogs, power management, network list, application restart/recovery, and property-system primitives (`PropertyKey`, `PropVariant`).

Install: `dotnet add package WindowsAPICodePackCore`

See the [repository README](https://github.com/Wagnerp/Windows-API-CodePack-NET) for TFMs, TaskDialog (comctl32 v6) notes, and license.
